Sideloadly ile Kurulum (önerilen)

  1. Yukarıdan .ipa dosyasını indir
  2. sideloadly.io programını bilgisayarına kur
  3. iPhone'u USB ile bağla
  4. ipa dosyasını pencereye sürükle + Apple ID gir
  5. Start → bitti ✅
Ücretsiz Apple ID yeterlidir · imza 7 gün geçerlidir, AltStore otomatik yeniler.
iOS 16+ cihazlarda ilk kurulumda Geliştirici Modu gerekebilir:
Ayarlar → Gizlilik ve Güvenlik → Geliştirici Modu → Aç

🤖 Android'de: indirilen .apk dosyasına dokun → "Bilinmeyen kaynağa izin ver" → Kur

🪟 Windows: .zip'i çıkar → melody.exe çalıştır · 🐧 Linux: .tar.gz çıkar → ./melody
