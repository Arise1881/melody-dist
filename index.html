iPhone Kurulumu

  1. Yukarıdan .ipa dosyasını indir (veya sağdaki QR'i telefon kamerasıyla okut → dosya telefona insin)
  2. sideloadly.io programını bilgisayarına kur
  3. iPhone'u USB ile bağla
  4. ipa dosyasını pencereye sürükle + Apple ID gir
  5. Start → bitti ✅

ℹ️ Apple güvenliği nedeniyle iOS'ta tarayıcıdan indirilen uygulama kendiliğinden kurulmaz; yukarıdaki tek seferlik imzalama adımı gereklidir. AltStore/SideStore kuruluysa "📲 AltStore'a Ekle" ile bilgisayarsız kurabilirsin.

📱 Telefonda Aç — IPA Direkt İndir

Kamera ile okut → .ipa dosyası telefona iner
(kurulum için üstteki imza adımı gerekir)

Ücretsiz Apple ID yeterlidir · imza 7 gün geçerlidir, AltStore otomatik yeniler.

Ayarlar → Gizlilik ve Güvenlik → Geliştirici Modu → Aç
