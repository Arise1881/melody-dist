4:50 dakikalık, Türkçe sesli anlatımlı videoyla iPhone'a bilgisayar kullanmadan kurulum: yöntem seçimi, SideStore kurulumu, Melody kaynağı ekleme ve 7 günlük otomatik yenileme.

📲 PC'siz Kurulum — SideStore (önerilen)

Apple, QR ile inen uygulamanın direkt kurulmasına izin vermez; cihaza önce ücretsiz SideStore kurulur, sonrası tamamen PC'siz. (Eski web.jitstreamer.com yöntemi kaldırıldı — site hizmet dışı.)

  1. iOS 27+ cihazlar: tarayıcıdan frizzlem.github.io/SideInstaller → SideInstaller uygulamasını kur → Apple ID'nle gir → Install SideStore → bitti ✅
  2. iOS 26 ve altı (gri alan, sertifika gerektirir): applejr.net üzerinden ESign kur, sonra SideStore IPA'sını cihazdan imzala
  3. SideStore → Settings → Sources → bu kaynağı ekle (veya alttaki SideStore QR'ini okut)
  4. Kaynak listesinden Melody → Install → Apple ID onayı ✅ + 7 günlük yenileme WiFi üzerinden otomatik

SideStore açıkken bu QR'ı okut → Melody kaynağı eklenir

iPhone Kurulumu — Bilgisayarla (ister) Bilgisayarsız (gri alan)

  1. Yukarıdan .ipa dosyasını indir (veya aşağıdaki iPhone QR'ini telefon kamerasıyla okut → dosya telefona insin)
  2. sideloadly.io programını bilgisayarına kur
  3. iPhone'u USB ile bağla
  4. ipa dosyasını pencereye sürükle + Apple ID gir
  5. Start → bitti ✅

ℹ️ Apple güvenliği nedeniyle iOS'ta tarayıcıdan indirilen uygulama kendiliğinden kurulmaz; tek seferlik imzalama adımı gerekir. AltStore/SideStore kuruluysa "📲 AltStore'a Ekle" ile bilgisayarsız kurabilirsin. Alternatif olarak ESign/Scarlet gibi cihaz-içi imzalayıcılar da var ama kritik/güvenilir değil.
